Sahyog – Smart Food Donation & NGO Management System

Sahyog is a web-based Smart Food Donation and NGO Management System that connects food donors with NGOs to reduce food wastage and help distribute surplus food to people in need.

Features
User Registration and Login
Donor and NGO Accounts
Donor Dashboard
NGO Dashboard
Food Donation Management
Food Listing
Food Claim Management
User Profile Management
Feedback System
Notifications
Responsive User Interface
Form Validation
MySQL Database Integration
Technologies Used
Frontend: HTML5, CSS3, JavaScript
Backend: PHP
Database: MySQL
Icons: Font Awesome
Server: XAMPP
Version Control: GitHub
